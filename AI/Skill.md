# Skill

- [anthropics skills](https://github.com/anthropics/skills)
    - Public repository for Agent Skills
- [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
    - An AI SKILL that provide design intelligence for building professional UI/UX multiple platforms
- [skills](https://github.com/antfu/skills)
    - Anthony Fu's curated collection of agent skills.
    - Vue、Nuxt、Pinia、Vite、Vitest、UnoCSS 等项目的官方文档，都被按一定结构整理成 AI 可以理解和调用的技能。
- [superpowers](https://github.com/obra/superpowers)
    - An agentic skills framework & software development methodology that works.
- [agent-skills](https://github.com/addyosmani/agent-skills)
    - Production-grade engineering skills for AI coding agents.
    - Addy Osmani 整理的生产级工程技能集，给 AI 编码 Agent 提供规划、测试、评审等工程实践技能。
- [modern-web-guidance-src](https://github.com/GoogleChrome/modern-web-guidance-src)
    - Keep your coding agent up to date with the latest web best practices
    - Chrome / Edge / Firefox / MDN 联合维护的现代 Web 技能集，把平台 API、性能和无障碍指南注入编码 Agent，避免生成过时写法。
- [SkillSpector](https://github.com/NVIDIA/SkillSpector)
    - Security scanner for AI agent skills. Detect vulnerabilities, malicious patterns, security risks, prompt injection, data exfiltration, and supply-chain risks in Claude Code, Codex, and MCP skills before you install them.
    - NVIDIA 开源的 Agent Skill 安全扫描器，在安装 Claude Code / Codex / MCP 技能前检测提示注入、数据外泄和供应链风险。
- [SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator)
    - Multi-tier framework for evaluating AI agent skills with quality gates, semantic overlap detection, synthetic evaluation.
    - NVIDIA 开源的 Agent Skill 多层评估框架，包含质量门禁、语义重叠检测和合成评测。
- [last30days-skill](https://github.com/mvanhorn/last30days-skill)
    - AI agent skill that researches any topic across Reddit, X, YouTube, HN, Polymarket, and the web - then synthesizes a grounded summary.
    - 让 Agent 跨 Reddit、X、YouTube、HN、Polymarket 和网页调研任意话题，并输出有出处的近 30 天综述。
- [stitch-skills](https://github.com/google-labs-code/stitch-skills)
    - A library of Agent Skills designed to work with the Stitch MCP server, following the Agent Skills open standard for Antigravity, Gemini CLI, Claude Code, Cursor.
    - Google Labs 出品的 Agent Skills 库，配合 Stitch MCP 服务使用，遵循 Agent Skills 开放标准，可用于 Gemini CLI、Claude Code、Cursor 等编码代理。
- [inference-optimisation-skill](https://github.com/sybil-solutions/inference-optimisation-skill)
    - Agent skill for hill-climbing local LLM serving speed (decode, speculative decoding, prefill, KV, startup, TTFT) on any hardware and quantization
    - 用于优化本地 LLM 推理速度的 Agent Skill：先算理论上限，再对 decode、投机解码、prefill、KV、TTFT 做对照实验。
