# 设计相关

 - [stitch](https://stitch.withgoogle.com/)
    - Start with a prompt. Iterate into a design.
 - [figma](https://www.figma.com/)
 - [astryx](https://github.com/meta/astryx)
    - An open source design system that's fully customizable and agent ready
    - Meta 开源的可定制、面向 Agent 的设计系统。
 - [ui](https://github.com/vercel-labs/ui)
    - A library of behaviors for agents to build and drive the next generation of user interfaces.
    - Vercel Labs 开源的 UI 行为库，让 Agent 组合无障碍界面（焦点、键盘、选择、拖放等），支持 React / Vue / Svelte / Solid 与 Web Components。
